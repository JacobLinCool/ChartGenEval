## Tests (per baseline x 9 edits: C1, C1s, C2, C3, C4, C5, C6, C7, C8)
- Frozen severities, doses, 5 seeds, song (group_id) clustering, 10,000 bootstrap draws,
  99.5% Bonferroni interval, >= 72/80 songs, frozen `_pair_group_values`/`_cluster_summary`.
- Bootstrap seed: frozen `_pair_seed(20260712, "POSTHOC_BASELINE__<probe>__<metric>")`.
- Orientation: frozen `_oriented` (value if worse=decrease else -value). Support = both
  99.5% upper bounds < 0 ("detects"). Frozen refutation = either lower bound >= 0.

## Invariance controls each baseline must pass (tolerance 1e-9 absolute, all charts)
- identity + joint time-origin shift: all baselines (reference chart shifted with the notes
  for onset F1, since the reference is aligned to the audio).
- C2 anchor shift (3 doses): chart-only baselines (perplexity, self-similarity, IOI JS).
- Don/Ka color bijection: time-only baselines (IOI JS, onset F1 x2).

## Matched control (sham) for the contrast statistic
The frozen matched control per edit (color swap for C1/C1s/C6/C7; joint shift for C2;
C2 strongest for C3/C4/C5/C8) when the baseline is required to be invariant to it;
otherwise CTRL_identity (== unedited chart). Rationale: a sham must be a change the metric
is supposed to ignore; otherwise the contrast measures the sham's own effect.

## Labels (descriptive, on top of the frozen verdict)
- detects: frozen SURVIVES.
- blind: every song's dose statistic and contrast exactly 0 (constant response).
- rewards: either 99.5% lower bound > 0 (moves significantly in the "better" direction).
- misses: anything else (REFUTED with a bound touching 0, or INCONCLUSIVE).
- control-fail: required control fails (frozen INCONCLUSIVE).
