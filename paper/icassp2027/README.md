# ICASSP 2027 submission

`paper.tex` builds the five-page submission PDF `paper.pdf`:
**ChartGenEval: Testing Rhythm-Game Chart Measurements with Controlled Errors**.
The manuscript follows Introduction, Methods, Results, and Discussion
(IMRaD), with limitations and conclusions within Discussion. The original
long-form manuscript remains in the parent directory.

## Build

Requires Python 3 and a TeX Live installation with `latexmk`, `spconf`'s
standard dependencies, TikZ, pgfplots, and `standalone`. The official style
files are included locally.

```sh
make
```

`make verify` additionally requires PyMuPDF and Poppler's `pdffonts`.
Figure sources are in `figs/`; `figs/style.tex` holds the shared line
weights and arrow tips. `make` first runs `figs/data/extract_offsets.py`,
which reads the repository's `artifacts/records/system_timing_clean.jsonl`
(Mapperatorinator, authored grid) and writes the per-chart offsets plotted in
Fig. 2b (`figs/data/fig2_offsets.dat`) and the medians and off-axis counts
printed on it (`figs/data/fig2_stats.tex`); it checks those numbers against
Sec. 3.4. `tables/build_results.py` produces the result table from the
included snapshot of the repository's
`artifacts/tables/confirmatory_primary_results.csv`, retaining all ten
prespecified rows in the CSV and displaying nine nonredundant rows, grouped
by property, with a Pass column derived from each row's recorded verdict.
`tables/build_baselines.py` builds Table 2 from
`tables/baselines_verdict_matrix.json`, a byte-identical copy of
`artifacts/posthoc_baselines_heldout/verdict_matrix.json`. The numbers cited
with Table 2 (`tables/baseline_numbers.tex`) were generated by that folder's
`make_tex.py`; see its README for the post hoc secondary analysis.

## Official template

Downloaded on 2026-09-16 from the ICASSP 2027 submission site:

- [Paper Kit](https://cmsworkshops.com/ICASSP2027/papers/paper_kit.php)
- [Official template ZIP](https://cmsworkshops.com/ICASSP2027/papers/PaperFormat/ICASSP2027_Paper_Templates.zip)
- [Submission and deadline information](https://cmsworkshops.com/ICASSP2027/papers.php)

`spconf.sty` and `IEEEbib.bst` are exact copies from the official template
ZIP.

The submission uses Letter paper, two columns, the official 9-point option,
and no page numbers. Technical material, including the AI-use disclosure,
ends on page 4. Page 5 contains only the Compliance with Ethical Standards
section (including the funding and conflict-of-interest statements) and
references.
